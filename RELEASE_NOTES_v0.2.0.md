# GENESIS Media Manager v0.2.0

## Schwerpunkt

Modernisierung der WPF-Oberflaeche nach der neuen GENESIS UI-Referenz.

## Highlights

- neue Sidebar mit Icons
- modernisierte Dashboard-Karten
- Pill-Aktionen
- verbesserte Statusanzeige
- Format-Chips
- Cover-Thumbnails in sichtbaren Medientabellenzeilen
- einheitliche dunkelblaue/charcoal Farbpalette
- Versionsstand des Core, WPF-Clients und Installers auf 0.2.0 angehoben

## Qualitaetsgrenzen

Kein Release-Gate-PASS wird allein durch diese UI-Aenderung behauptet. Der finale Release-Status bleibt von Build, Tests, Security/Regression und realer Windows-UI-Pruefung abhaengig.
