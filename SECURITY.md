# Security Policy / Sicherheitsrichtlinie

## Deutsch

Dieses Repository enthält Dokumentation und Prompt-Vorlagen, keine ausführbare Anwendung.
Trotzdem können fehlerhafte Empfehlungen, ungewollte Offenlegung von Geheimnissen oder
problematische Release-Artefakte sicherheitsrelevant sein.

**Bitte keine Sicherheitsdetails in einem öffentlichen Issue veröffentlichen.** Nutze stattdessen
die Funktion **GitHub Private Vulnerability Reporting / Security Advisories** des Ziel-Repositorys.
Falls diese Funktion nicht aktiviert ist, eröffne nur ein minimales öffentliches Issue ohne sensible
Details und bitte um einen privaten Kommunikationsweg.

Melde dabei möglichst: betroffene Datei/Version, Auswirkung, Reproduktionsschritte ohne echte
Geheimnisse sowie einen möglichen Fix. Es gibt keine garantierte Bearbeitungsfrist; bestätige
kritische Risiken vor Nutzung oder Veröffentlichung unabhängig.

## English

This repository contains documentation and prompt templates, not an executable application.
Nevertheless, incorrect guidance, accidental secret exposure, or problematic release artifacts
can have security relevance.

**Do not disclose security details in a public issue.** Use the target repository’s
**GitHub Private Vulnerability Reporting / Security Advisories** feature instead. If it is not enabled,
open only a minimal public issue without sensitive details and request a private communication channel.

Where possible, report the affected file/version, impact, reproduction steps without real secrets,
and a potential fix. No response deadline is guaranteed; independently validate critical risks before
using or publishing the material.
