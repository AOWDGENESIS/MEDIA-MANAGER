# 1. Repository erstellen / Create repository

## Deutsch — GitHub-Weboberfläche

1. Auf GitHub oben rechts **+** → **New repository**.
2. Repository name: `ai-deep-review-prompt-pack`.
3. Description: `Bilingual, evidence-based AI prompts for deep code, security, reliability, and release reviews.`
4. Sichtbarkeit wählen: **Public** für frei nutzbare Vorlagen oder **Private** für interne Nutzung.
5. **Nicht** „Add a README file“, `.gitignore` oder License auswählen. Diese Release-Datei enthält sie bereits.
6. **Create repository** auswählen.
7. Repository-URL kopieren. Beispiel: `https://github.com/ORG_OR_USER/ai-deep-review-prompt-pack.git`.

## English — GitHub web interface

1. On GitHub, select **+** → **New repository**.
2. Repository name: `ai-deep-review-prompt-pack`.
3. Description: `Bilingual, evidence-based AI prompts for deep code, security, reliability, and release reviews.`
4. Choose visibility: **Public** for reusable templates or **Private** for internal use.
5. Do **not** select “Add a README file”, `.gitignore`, or License. They are already in this release.
6. Select **Create repository**.
7. Copy the repository URL, for example: `https://github.com/ORG_OR_USER/ai-deep-review-prompt-pack.git`.
