# Code of Conduct / Verhaltenskodex

## Deutsch

Mitwirkende behandeln andere respektvoll und sachlich. Belästigung, Diskriminierung,
Beleidigungen, die Veröffentlichung privater oder sensitiver Informationen und absichtlich
irreführende Sicherheitsbehauptungen werden nicht akzeptiert. Technische Kritik soll sich auf
Code, Texte, Belege und Auswirkungen beziehen, nicht auf Personen.

Melde Verstöße über die privaten GitHub-Sicherheits- oder Kontaktfunktionen des Repositorys.

## English

Contributors must treat others respectfully and professionally. Harassment, discrimination,
insults, disclosure of private or sensitive information, and deliberately misleading security
claims are not accepted. Technical criticism must address code, text, evidence, and impact,
not people.

Report violations through the repository’s private GitHub security or contact facilities.
