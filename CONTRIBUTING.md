# Contributing / Mitwirken

## Deutsch

1. Eröffne zuerst ein Issue für größere Struktur- oder Regeländerungen.
2. Halte den deutschen und englischen Prompt **inhaltlich gleichwertig**. Jede neue Profilüberschrift,
   Kernregel und Referenz muss in beiden Fassungen ergänzt werden.
3. Verwende nur belastbare, bevorzugt offizielle Primärquellen. Verlinke stabile HTTPS-URLs.
4. Keine Geheimnisse, personenbezogenen Testdaten, ausführbaren Payloads oder fremden Texte ohne
   eindeutige Lizenzgrundlage einreichen.
5. Halte Änderungen klein, begründe sie, aktualisiere `CHANGELOG.md` und führe
   `python3 scripts/validate_release.py` aus.
6. Stil: Imperative, agentenlesbare Aussagen mit MUST/MUST NOT bzw. MUSS/MUSS NICHT;
   keine unbelegten Sicherheitsbehauptungen.

## English

1. Open an issue before making larger structural or rule changes.
2. Keep the German and English prompts **semantically equivalent**. Add every new profile heading,
   core rule, and reference to both editions.
3. Use reliable, preferably official primary sources. Link stable HTTPS URLs.
4. Do not submit secrets, personal test data, executable payloads, or third-party text without a clear license basis.
5. Keep changes small, explain them, update `CHANGELOG.md`, and run
   `python3 scripts/validate_release.py`.
6. Style: imperative, agent-readable statements using MUST/MUST NOT; avoid unsupported security claims.
