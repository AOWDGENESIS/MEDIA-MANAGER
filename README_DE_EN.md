# GitHub Setup / GitHub-Einrichtung

**Version:** 1.2.2

## Deutsch

Arbeite die Dateien in dieser Reihenfolge ab. Die Anleitungen betreffen ausschließlich dieses
Prompt-Paket; vermische es nicht mit einem Quellcodeprojekt oder einer anderen Release-Version.

1. `01_CREATE_REPOSITORY_DE_EN.md` — neues, leeres Repository anlegen.
2. `02_UPLOAD_CONTENT_DE_EN.md` — ausschließlich den entpackten Inhalt dieses Release-Ordners hochladen.
3. `03_SECURITY_AND_BRANCH_SETTINGS_DE_EN.md` — GitHub-Einstellungen setzen.
4. `04_PUBLISH_RELEASE_DE_EN.md` — Release `v1.2.2` mit ZIP, SHA-256 und Release Notes veröffentlichen.
5. `05_OPTIONAL_CODEOWNERS_DE_EN.md` — optionalen CODEOWNERS-Schutz ohne Platzhalterfehler einrichten.
6. `06_APPLY_REMOTE_FIX_v1.2.2_DE_EN.md` — bestehenden Remote-Stand auf v1.2.2 korrigieren.

## English

Follow these files in order. These instructions apply only to this prompt package; do not mix it
with a source-code project or another release version.

1. `01_CREATE_REPOSITORY_DE_EN.md` — create a new empty repository.
2. `02_UPLOAD_CONTENT_DE_EN.md` — upload only the extracted content of this release folder.
3. `03_SECURITY_AND_BRANCH_SETTINGS_DE_EN.md` — apply GitHub settings.
4. `04_PUBLISH_RELEASE_DE_EN.md` — publish release `v1.2.2` with ZIP, SHA-256, and release notes.
5. `05_OPTIONAL_CODEOWNERS_DE_EN.md` — configure optional CODEOWNERS protection without placeholder errors.
6. `06_APPLY_REMOTE_FIX_v1.2.2_DE_EN.md` — correct an existing remote repository to v1.2.2.
